# 大狗Tap DJ版

一个基于 Web Audio API 的全屏节奏演奏网页。默认开启三台 Deck，左、中、右依次使用大狗叫、哈基米、叮咚鸡；支持多点触控、键盘演奏、节奏吸附、跟手特效和双声道立体声。

## 在线体验

- [飞书妙搭](https://t9lqe93khi.feishuapp.com/app/app_17ammbtgvq8/)
- [GitHub Pages](https://jzlikewei.github.io/Dagou-Tap-New/)

首次进入时点一下开始遮罩，用于解锁浏览器音频。iPad Safari 的音频启动发生在抬手阶段；启动超时后可以再次点击。

当前公开测试版已解锁三套音效，打开 DJ 模式即可直接体验。

## 主要玩法

### DJ 模式

- 默认使用 3 Deck，支持切换为 2 Deck。
- 每台 Deck 都有完整的 `4 × 3` 演奏网格。
- 每台 Deck 可以独立选择大狗叫、哈基米或叮咚鸡。
- 多根手指可以同时演奏不同 Deck。
- 第三行支持长按延音，同一 Deck 内拖动可以连续变调。
- 跟手特效支持普通几何样式与大狗、猫、鸡图片样式，图片跟随 Deck 音色切换，两种样式都保留触点圆圈。
- 角色图片松手后会轻微放大，在约 200 毫秒内淡出并沿手势方向飞离。
- “录制&分享”面板默认录制 30 秒，可切换为 60 秒；录制可命名并存入当前浏览器的本机曲库。

默认三区顺序：

```text
LEFT       CENTER     RIGHT
大狗叫      哈基米      叮咚鸡
```

### DJ 录制与回放

- 舞台顶部控制条提供单一“录制&分享”入口；面板内可切换“录制”“导入”和“曲库”。第一次发声成为时间零点，录制状态栏可随时停止；最后 5 秒会变红并逐秒倒计时。
- 录制保存音频时钟上的按下、双押、第三行长按、同 Deck 滑音和松开时间，回放继续走正式 Web Audio 调度器，并同步重现区块闪光、全屏效果和跟手图片。
- 分享码同时保存 Deck 数量、三区音色、节奏吸附、跟手样式、立体声开关和背景节拍相位。立体声只占一个标志位。
- `DGT2` 头部为 4–7 字节，固定使用 128 BPM，省去音符数量和额外声像位置。数据带 CRC32 校验，重复片段会经过无损 LZSS 压缩，再转换成 Base64url；前缀为 `DGT2R.` 或 `DGT2Z.`，旧 `DGT1` 分享码仍可导入。
- 录制完成后可填写曲目名称、存入曲库或复制分享码。名称使用 UTF-8，最多 8 字节。
- “生成分享链接”会把命名分享码写入飞书妙搭地址的 `dj` 查询参数并复制完整 URL。接收方打开链接、首次点击解锁音频后会自动进入 DJ 模式并播放。
- 命名分享使用 `DGL1` 外层封装名称与原始 `DGT2` 数据；导入时自动恢复名称。旧 `DGT1 / DGT2` 分享码继续兼容，导入后会补充默认名称。
- 将分享码粘贴到“导入”页后会同步存入曲库，并可播放复现录制配置；开启“循环播放”后会按音频时钟连续重播，手动停止后恢复进入播放前的设置。
- 本机曲库通过 `localStorage` 保存最多 50 首曲目，可查看详情、改名、播放、导出分享码、生成飞书分享链接和删除。曲库跟随当前浏览器与站点来源，清理网站数据时会一并清除。
- 新录制提供 `0:30` 与 `1:00` 两档，默认 `0:30`；旧分享码仍按最长 90 秒兼容导入。音符上限为 5000，分享码上限为 32768 个字符。

### 音游模式

- 设置项显示为“音游模式（不好玩）”。
- 音游拥有独立模式开关，与 DJ、钢琴模式互斥。
- 每局按当前 `128 BPM` 随机生成 8 组四小节乐句，共 `32` 小节，固定 `1:00`。
- 栏数可以选择 1、2、3；每栏使用完整 `4 × 3` 网格，分别提供 12、24、36 个区域。
- 网格会在音游期间自动显示，八边形目标提前约 1.2 秒出现并收缩到目标格。
- 每四组依次走主题、问答、提升、收束；组内使用重复、接龙、留白和双押落点，同一乐句的音高只停留或移动到相邻列。
- 同一句口号有多种八分音符节奏型，会交替从正拍、反拍和拉开的位置进入。音色口号包含“大狗叫”“大狗大狗叫叫叫”“叮咚叮咚鸡”以及各自的短句变体。
- 每四小节固定包含 2–3 个持续句尾；“叫、米、鸡”承担长音，其他 Deck 在长音上方穿插短句。普通短句降低密度，连续音节使用更长的发声时值。
- 谱面包含单点、2–3 栏中的跨栏双押，以及第三行延音区域的长音与连音链。
- 连音链会分别判定起按、每次滑入相邻目标格和末端松手；提前松开、滑错区域或松晚都会中断。
- 连音期间只在其他栏安排单点，整张谱面最多同时占用两根手指。
- 普通音符只统计按下动作；连音链需要保持按住并跟随目标滑动。键盘可按住起点键，再按提示键完成换音，最后松开起点键。
- 判定分为“完美、良好、漏拍”，结算显示分数、命中率和最高连击。
- 音游使用实际按下时间进行判定，并临时绕过“强化节奏”的输入排队；退出后原设置继续生效。
- 音游期间从纸屑、折线、几何雨和星星中每次随机一种，围绕目标格缩小到原范围的 34%，短暂展开后自动退场。点击时整个格子按音色着色，中央显示对应角色的张嘴图片；长尾迹收起，触点处保留小范围扩散环或 Emoji 弹出。
- 设置里的 `AUTO 自动演奏` 会按谱面自动短按、双押、拖动连音链并按时松手，沿用同一套声音与完整判定。独立短音保持 120 毫秒，句内连奏保持 200 毫秒，持续句尾按谱面时值完整释放。

### 普通模式与钢琴模式

- 普通模式按固定音阶触发当前音效。
- 钢琴模式提供 C4–C5 的八个白键音阶。
- DJ、音游、钢琴模式互斥，开启其中一个会直接切换演奏模式。
- “强化节奏”会把输入吸附到连续八分音符拍点。
- “显示网格”控制演奏分区的细网格显示。

### 双声道立体声

- 顶部工具栏和设置菜单都提供立体声开关，两处状态同步。
- 一栏模式保持居中；两栏模式分别放在左、右；三栏模式依次放在左、中、右。
- 开启时使用 `StereoPannerNode` 调整各栏声像，关闭后所有音效回到中央。
- 背景音乐保持居中，录制与分享只保存立体声开关。

### 横屏演奏

- iPhone 和 iPad 的设置菜单会显示“横屏演奏”。
- 开启后先请求页面全屏，再请求系统锁定横屏。
- 浏览器拒绝方向锁定时，页面会提示手动旋转，并保留“尝试自动横屏”和关闭入口。
- 关闭时解除方向锁定，只退出页面自行进入的全屏。
- 该选择保存在当前设备。

## DJ 键盘布局

键盘按物理位置读取，输入法状态不会改变按键映射。
PC 端可用左上角“展示快捷键”临时打开当前 Deck 键位，再次点击即可收起；该操作不会改动“网格线”设置。

| 音节 | LEFT | CENTER | RIGHT |
| --- | --- | --- | --- |
| 第一行 | `1 2 3 4` | `5 6 7 8` | `9 0 - =` |
| 第二行 | `Q W E R` | `T Y U I` | `O P [ ]` |
| 第三行 | `A S D F` | `G H J K` | <code>L ; ' &#92;</code> |

两台 Deck 使用 LEFT 和 RIGHT；三台 Deck 使用全部三组。按住第三行按键可以延音，多键可以同时触发。

## 本地运行

项目是原生 HTML、CSS 和 JavaScript 静态网页，无需安装运行依赖。

```bash
python3 -m http.server 8765
```

然后访问 [http://127.0.0.1:8765/](http://127.0.0.1:8765/)。

## 项目结构

```text
index.html       页面结构与样式
main.js          音频、演奏模式、交互与设备能力
audio-data.js    网页运行时使用的内嵌音频数据
audio/           原始 WAV 音频
Image/           角色、封面与动画素材
tools/           音频分析、数据构建与自动验证
docs/            音高说明与 DJ 开发交接文档
```

哔哩哔哩 Toy 环境会读取和保存解锁状态及演奏设置。独立网页会自动进入本地模式；横屏演奏偏好使用浏览器本机存储。

## 自动验证

```bash
node --check main.js
node tools/verify_runtime_mapping.mjs
node tools/verify_interaction_queue.mjs
node tools/verify_toy_cloud_flow.mjs
node tools/verify_dj_mode.mjs
node tools/verify_dj_recording.mjs
node tools/verify_rhythm_game.mjs
node tools/verify_stereo_audio.mjs
node tools/verify_mobile_startup.mjs
```

修改音频或音高映射时，先运行分析和数据构建：

```bash
python3 tools/analyze_pitch.py --write-wavs
node tools/build_audio_data.mjs
```

详细说明见 [开发与音高验证工具](tools/README.md)、[音频与和声说明](docs/audio-pitch-harmony.md) 和 [DJ 模式开发交接](docs/dj-mode-handoff.md)。
